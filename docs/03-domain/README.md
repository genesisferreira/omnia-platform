# Domain Model

## Finalidade

Documentação do **modelo de domínio** seguindo Domain-Driven Design: bounded contexts, entidades, agregados, value objects, eventos de domínio e linguagem ubíqua.

- Bounded contexts por módulo
- Diagramas de entidades e relacionamentos
- Glossário de termos de domínio
- Regras de invariantes
- Eventos de domínio
