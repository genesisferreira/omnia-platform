# Design System

> Sistema de design da Omnia Platform.

## Finalidade

Documentação do **design system** baseado em shadcn/ui e Tailwind CSS, incluindo tokens, componentes, padrões visuais e guidelines de acessibilidade.

## Conteúdo Esperado

- Tokens de design (cores, tipografia, espaçamento)
- Catálogo de componentes (packages/ui)
- Guidelines de acessibilidade (WCAG 2.1 AA)
- Padrões de layout e grid
- Branding e identidade visual

## Responsável

Design / Engenharia Frontend
