## Resumo

Sprint 1 transforma a fundação documental em uma **base executável** com Next.js 15, Payload CMS, Drizzle ORM e Docker Compose.

## Entregas

### Aplicações

- `apps/web` — Next.js 15, Tailwind, página placeholder, `/api/health`
- `apps/admin` — Next.js 15, Payload CMS, página placeholder, `/admin`

### Packages

- `@omnia/database` — Drizzle ORM, conexão PostgreSQL
- `@omnia/ui` — shadcn/ui preparado (Button, tokens, globals.css)
- `@omnia/auth` — estrutura para Sprint 2

### Infraestrutura

- Docker Compose: PostgreSQL 16, Redis 7, MinIO, n8n
- Scripts: `docker:dev`, `docker:down`, `docker:logs`

### Documentação

- SPRINT-01-INFRASTRUCTURE, ARCHITECTURE, DATABASE, STATUS
- CHANGELOG.md atualizado

## Como rodar

```bash
cp .env.example .env
pnpm install
pnpm docker:dev
pnpm dev
```

| App           | URL                         |
| ------------- | --------------------------- |
| Web           | http://localhost:3000       |
| Admin         | http://localhost:3001       |
| Payload CMS   | http://localhost:3001/admin |
| n8n           | http://localhost:5678       |
| MinIO Console | http://localhost:9001       |

## Não incluído

Login, RBAC, CRM, marketplace, blog, IA, chat, automações reais.
