# Sprint 0 — Release Notes

> Fundação da Omnia Platform — v0.1.0-sprint0

**Data:** 2026-07-07  
**Status:** ✅ Concluída

---

## Resumo

Sprint 0 estabeleceu a fundação completa do monorepo: estrutura de pastas, workspaces funcionais, toolchain TypeScript/ESLint/Prettier, CI/CD, documentação e decisões arquiteturais formais.

## Entregas

### Monorepo

- 2 apps (`@omnia/web`, `@omnia/admin`)
- 6 packages (`@omnia/shared`, `@omnia/database`, `@omnia/ui`, `@omnia/auth`, `@omnia/ai-core`, `@omnia/automation`)
- pnpm workspaces com catalog de dependências
- Turborepo com tasks: build, dev, lint, typecheck, clean

### Toolchain

- TypeScript 5.7 strict (`tsconfig.base.json`)
- ESLint com `@typescript-eslint`
- Prettier + EditorConfig
- VS Code settings e extensions recomendadas

### CI/CD

- GitHub Actions: lint, typecheck, format check, build
- `pnpm-lock.yaml` versionado

### Documentação

- 21 seções em `docs/` com READMEs
- ADR-001 (Monorepo Modular) e ADR-002 (Drizzle ORM)
- Templates GitHub (PR, issues, CONTRIBUTING, SECURITY)
- Cursor AI rules e contexto

### Infraestrutura (preparada)

- Estrutura Docker, config por ambiente, scripts operacionais
- `.env.example` com variáveis planejadas

## Não incluído (Sprint 1+)

- Next.js 15 e Payload CMS
- Docker Compose funcional
- Drizzle ORM implementado
- Código de negócio

## Como validar

```bash
# Requer Node.js 22+ e pnpm 9+
pnpm install   # gera pnpm-lock.yaml
pnpm lint
pnpm typecheck
pnpm format:check
pnpm build
```
