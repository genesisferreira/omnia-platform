- Payload CMS funcional com 4 coleções + 1 global

- Portal com homepage completa (Hero, Ecossistema, Empresas, CTA)

- Global: `global-settings`

## Packages alterados

- `@omnia/config` — implementação runtime
- `@omnia/ui` — tokens Omnia + novos componentes

## Como atualizar

```bash
git checkout feature/sprint-02-platform-base
pnpm install
cp .env.example .env
pnpm docker:dev
pnpm --filter @omnia/admin seed
pnpm dev
```
