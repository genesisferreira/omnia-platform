# Meetings

> Atas e registros de reuniões.

## Finalidade

Arquivo de **atas de reuniões** técnicas, de produto, sprint planning, retrospectivas e decisões tomadas em reunião.

## Conteúdo Esperado

- Sprint planning notes
- Retrospectivas
- Decisões técnicas em reunião
- Action items e responsáveis
- Participantes e data

## Responsável

Scrum Master / Product Owner

## Convenção de Nomenclatura

```
YYYY-MM-DD-tipo-assunto.md
```

Exemplo: `2026-07-07-sprint-planning-sprint-1.md`
