# ADR — Architecture Decision Records

> Registros de decisões arquiteturais da Omnia Platform.

## Finalidade

Documentação formal de **decisões arquiteturais** significativas, incluindo contexto, alternativas consideradas, decisão tomada e consequências.

## Formato

Cada ADR segue o template:

1. **Título** — decisão em uma frase
2. **Status** — proposto, aceito, depreciado, substituído
3. **Contexto** — problema ou necessidade
4. **Decisão** — o que foi decidido
5. **Alternativas** — opções consideradas
6. **Consequências** — impactos positivos e negativos
