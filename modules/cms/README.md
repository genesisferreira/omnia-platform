# Módulo — CMS

Bounded context de **gestão de conteúdo** via Payload CMS.

## Escopo

- Coleções de conteúdo (páginas, posts, mídia)
- Usuários e permissões admin
- Media library (MinIO)
- Preview e publicação

## Packages

`@omnia/integrations/payload` · `@omnia/auth`

## Nota

Payload CMS mantém seu próprio ORM. Dados CMS ≠ dados de aplicação (Drizzle — ADR-002).
